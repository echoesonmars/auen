# Инструкция по миграции изображений в Cloudinary

## Шаг 1: Добавьте переменные окружения в .env.local

Откройте файл `.env.local` и добавьте переменные Cloudinary (те же, что вы добавили в Vercel):

```
CLOUDINARY_CLOUD_NAME=ваш_cloud_name
CLOUDINARY_API_KEY=ваш_api_key
CLOUDINARY_API_SECRET=ваш_api_secret
```

## Шаг 2: Запустите скрипт миграции

```bash
npm run migrate-images
```

Скрипт:
1. Найдет все объявления с изображениями в базе данных
2. Проверит, есть ли локальные файлы в `public/uploads/ads`
3. Загрузит их в Cloudinary
4. Обновит пути в базе данных на URL Cloudinary
5. Сделает то же самое для аватаров пользователей

## Что будет происходить:

- ✅ Изображения с путями `/uploads/ads/...` будут загружены в Cloudinary
- ✅ Пути в базе данных обновятся на полные URL Cloudinary (https://res.cloudinary.com/...)
- ✅ Старые изображения, которых нет локально, останутся со старыми путями (но они не будут работать на Vercel)

## После миграции:

1. Все изображения будут в Cloudinary
2. Они будут отображаться на Vercel
3. Новые загрузки автоматически будут попадать в Cloudinary

## Важно:

- Убедитесь, что у вас есть локальные файлы в `public/uploads/ads` и `public/uploads/avatars`
- Скрипт пропустит изображения, которые уже имеют URL Cloudinary
- Если файл не найден локально, старый путь останется в базе данных
