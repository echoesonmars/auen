# Назначение администратора через MongoDB Compass

## Пошаговая инструкция

### Шаг 1: Откройте MongoDB Compass

1. Запустите MongoDB Compass
2. Подключитесь к вашей базе данных
3. Выберите базу данных `auen` (или другую, которую вы используете)

### Шаг 2: Найдите пользователя

1. В левой панели выберите коллекцию `users`
2. Найдите пользователя, которого хотите сделать администратором
3. Можно использовать поиск по email в верхней части

### Шаг 3: Добавьте поле `role`

**Вариант А: Редактирование документа**

1. Кликните на документ пользователя (откроется в правой панели)
2. Нажмите кнопку **"UPDATE"** внизу справа
3. Нажмите кнопку **"INSERT FIELD"** (или "+" для добавления поля)
4. В поле **Field** введите: `role`
5. В поле **Value** введите: `admin` (как строку)
6. Убедитесь, что тип данных **String**
7. Нажмите **"UPDATE"** для сохранения

**Вариант Б: Редактирование JSON**

1. Откройте документ пользователя
2. Нажмите кнопку **"UPDATE"**
3. Переключитесь в режим **List** или **JSON** (если доступно)
4. Добавьте новую строку после поля `password`:
   ```json
   "role": "admin"
   ```
5. Нажмите **"UPDATE"** для сохранения

**Вариант В: Через Document View**

1. Кликните на документ
2. В правой панели найдите кнопку переключения вида (List/Table/JSON)
3. Выберите **List** или **JSON**
4. Добавьте строку:
   ```json
   {
     ...остальные поля...,
     "role": "admin"
   }
   ```
5. Сохраните изменения

### Шаг 4: Проверка

После добавления поля ваш документ должен выглядеть так:

```json
{
  "_id": ObjectId("..."),
  "name": "alimzhan",
  "email": "admin@gmail.com",
  "phone": "+77777777777",
  "password": "$2b$10$...",
  "role": "admin",  // ← Это поле должно быть здесь
  "createdAt": ISODate("2025-11-23T15:37:29.891Z"),
  "updatedAt": ISODate("2025-11-23T15:37:29.891Z"),
  "__v": 0
}
```

### Шаг 5: Проверьте доступ

1. Выйдите из системы (если залогинены)
2. Войдите снова с этим email и паролем
3. Откройте админ-панель: `http://localhost:3000/admin`
4. В навбаре должна появиться кнопка "Админ"

## Альтернативный способ: MongoDB Shell

Если не получается через Compass, используйте MongoDB Shell:

1. Откройте терминал
2. Подключитесь к MongoDB:
   ```bash
   mongosh "mongodb+srv://your-connection-string"
   ```
3. Выполните команду:
   ```javascript
   use auen
   
   db.users.updateOne(
     { email: "admin@gmail.com" },
     { $set: { role: "admin" } }
   )
   ```
4. Проверьте результат:
   ```javascript
   db.users.findOne({ email: "admin@gmail.com" })
   ```

## Возможные проблемы

❌ **Кнопка UPDATE не активна**
- Убедитесь, что вы изменили документ
- Попробуйте сначала добавить поле, затем нажмете UPDATE

❌ **Поле не сохраняется**
- Убедитесь, что значение `"admin"` в кавычках (строка)
- Проверьте, что используете правильную базу данных

❌ **Не могу найти пользователя**
- Используйте поиск по email
- Проверьте, что пользователь зарегистрирован

## Быстрый способ через скрипт

Если ничего не помогает, используйте готовый скрипт:

```bash
npm run set-admin "admin@gmail.com"
```

Это автоматически добавит поле `role: "admin"` пользователю.
