ИНСТРУКЦИЯ ПО ОБНОВЛЕНИЮ В COMPASS:

1. Откройте MongoDB Compass
2. Выберите базу данных "auen"
3. Для коллекции "ads":
   - Перейдите в Validation
   - Найдите поле "images" в properties
   - Обновите его согласно новой валидации выше
   - Сохраните изменения

4. Для коллекции "users":
   - Перейдите в Validation
   - Найдите поле "avatar" в properties
   - Обновите его согласно новой валидации выше
   - Сохраните изменения

ИЛИ используйте команды из mongodb-ads-images-validation-update.js и mongodb-users-avatar-validation-update.js
