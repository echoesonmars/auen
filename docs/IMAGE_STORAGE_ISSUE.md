# Проблема с изображениями в Production

## Проблема
В production окружениях (например, Vercel) файловая система доступна только для чтения, и файлы не сохраняются между деплоями. Изображения, сохраненные в `public/uploads/ads/`, не будут доступны после деплоя.

## Решения

### Вариант 1: Использовать внешнее хранилище (рекомендуется)
- Cloudinary
- AWS S3
- Cloudflare R2
- ImgBB

### Вариант 2: Использовать Vercel Blob Storage
- Интегрировать Vercel Blob Storage для хранения изображений

### Вариант 3: Временное решение
- Убедиться, что пути к изображениям правильные
- Добавить fallback для случаев, когда изображения не найдены
- Использовать placeholder изображения

## Обновленные валидации
Валидации MongoDB обновлены, чтобы разрешить `null` для поля `images`:
- `"bsonType": ["array", "null"]` - массив может быть null
