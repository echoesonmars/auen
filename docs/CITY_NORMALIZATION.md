# Нормализация городов

## Проблема

При создании объявлений пользователи могут вводить названия городов в разных вариантах:
- "shymkent" и "шымкент" - один город, но создаются как разные
- Координаты вместо названия города
- Адреса вместо городов

## Решение

Реализована система нормализации названий городов, которая:
1. Приводит разные варианты написания к единому виду
2. Фильтрует координаты и адреса
3. Объединяет дубликаты городов

## Использование

### Автоматическая нормализация

При создании или обновлении объявления город автоматически нормализуется:
- "shymkent" → "Шымкент"
- "шымкент" → "Шымкент"
- "almaty" → "Алматы"
- "алматы" → "Алматы"

### Нормализация существующих данных

Для нормализации уже существующих объявлений запустите скрипт:

```bash
npm run normalize-cities
```

Этот скрипт:
- Нормализует все названия городов в объявлениях
- Пересоздает локации с нормализованными названиями
- Удаляет дубликаты

### API Locations

API `/api/locations` автоматически:
- Фильтрует не-города (координаты, адреса)
- Объединяет варианты написания одного города
- Удаляет локации с нулевым количеством объявлений
- Удаляет локации, которые не являются городами

## Поддерживаемые города

Система знает основные города Казахстана:
- Алматы (Almaty, Alma-Ata)
- Астана (Astana, Nur-Sultan, Nursultan)
- Шымкент (Shymkent, Chimkent)
- Караганда (Karaganda, Karagandy)
- И другие крупные города

## Функции

### `normalizeCityName(cityName: string): string`
Приводит название города к единому виду.

### `isCityName(location: string): boolean`
Проверяет, является ли строка названием города (не координаты, не адрес).

## Примеры

```typescript
import { normalizeCityName, isCityName } from "@/lib/cityNormalizer";

// Нормализация
normalizeCityName("shymkent"); // "Шымкент"
normalizeCityName("шымкент"); // "Шымкент"
normalizeCityName("Shymkent"); // "Шымкент"

// Проверка
isCityName("51.1694, 71.4491"); // false (координаты)
isCityName("улица Абая, 150"); // false (адрес)
isCityName("Алматы"); // true
isCityName("Almaty"); // true
```
