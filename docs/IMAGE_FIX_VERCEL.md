# Проблема с изображениями на Vercel

## Проблема
Старые изображения в базе данных имеют пути типа `/uploads/ads/filename.jpg`, но на Vercel эти файлы не существуют, потому что:
1. Файловая система на Vercel read-only
2. Файлы из `public/uploads` не деплоятся автоматически
3. Старые изображения были загружены локально и не попали в production

## Решения

### Вариант 1: Настроить Cloudinary (рекомендуется)
1. Зарегистрируйтесь на Cloudinary
2. Добавьте переменные окружения в Vercel:
   - `CLOUDINARY_CLOUD_NAME`
   - `CLOUDINARY_API_KEY`
   - `CLOUDINARY_API_SECRET`
3. Новые изображения будут загружаться в Cloudinary
4. Старые изображения нужно будет загрузить заново

### Вариант 2: Использовать CDN для старых изображений
Если у вас есть старые изображения на другом сервере:
1. Добавьте переменную окружения `NEXT_PUBLIC_IMAGE_BASE_URL` в Vercel
2. Укажите базовый URL вашего CDN (например, `https://cdn.example.com`)
3. Старые изображения будут загружаться с CDN

### Вариант 3: Загрузить изображения в public/uploads и закоммитить
1. Скопируйте все изображения в `public/uploads/ads` и `public/uploads/avatars`
2. Закоммитьте их в git
3. После деплоя они будут доступны

**Примечание:** Этот вариант не рекомендуется для production, так как увеличивает размер репозитория.

## Проверка
После настройки Cloudinary:
- Новые изображения будут загружаться в Cloudinary
- URL будут вида `https://res.cloudinary.com/...`
- Старые изображения с путями `/uploads/...` не будут работать (нужно загрузить заново)
